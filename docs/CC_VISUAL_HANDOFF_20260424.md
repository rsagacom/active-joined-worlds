## 2026-04-25 更新：住宅 / 主城图层合同

后续不要再扩展成复杂控制台。当前确认的方向如下：

- `creative.html` 这类现代室内像素场景可以作为“住宅 / 房间 / 私聊场所”的视觉样板。
- `index.html` 是“主城 / 群聊场所”，需要单独生成中国现代城区风格整图，不沿用住宅室内素材。
- 底图优先使用完整场景图，不要把素材表随便堆砌成背景。
- 最上层是文字对话层：消息仍按微信式瀑布流滚动，左侧是对方消息，右侧是己方消息。
- 点击场景空白区域时，文字对话层隐藏；再次点击场景空白区域，文字对话层恢复。
- 文字层隐藏时，不显示“对话框”悬浮小标签，应该真正清屏，让用户看完整像素场景。
- 文字层下方是透明热点层：覆盖在场景物件上，默认不可见；鼠标 hover / 键盘 focus 时才显示标签，例如“相册”“公告栏”“地铁口”。
- 点击热点只打开该热点的小交互浮层，不触发文字层隐藏/恢复。
- `住宅` 与 `主城` 两页都应复用这套层级：`背景整图 < 热点层 < 文字对话层 < 输入栏/HUD`。

主城整图要求：

- 风格：中国现代城区，不要仙侠、武侠或古代建筑。
- 构图：像素风 / 2.5D / SFC 游戏场景感，包含现代居民楼、街区广场、地铁口、便利店/咖啡店、公告栏、路灯、树池、长椅、城市天际线。
- 留出可点击热点语义：地铁口、公告栏、广场中心、商铺、相册/照片墙可后续映射。
- 不要在图片里生成可读文字、按钮、输入框或 UI 面板；所有文字和 UI 都由 HTML/CSS 叠加。
- 画面需要有完整地面/道路/广场铺装，不能留白。
