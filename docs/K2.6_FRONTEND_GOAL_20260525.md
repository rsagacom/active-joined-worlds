Gateway 端已就绪的能力：

- `GET /v1/admin/conversations` — 全部会话列表（含标题、类型、成员数、消息数、冻结状态）

- `POST /v1/shell/message` / `POST /v1/shell/message/edit` / `POST /v1/shell/message/recall` — 消息写操作
- 所有写操作已通过 `postGatewayJson()` 统一传 bearer token（`shell-gateway.js` L6）
