| # | 问题 | 证据 | 影响 |

## 二、设计原则

1. **守约束**:严格遵守 ASSET_HANDOFF.md 美术收口 —— 暗棕黑 `#16100c~#22181c` 面板、边框 `#2c2622`,禁大块金色/cream,金色仅小字符高亮;像素场景图与昼夜机制不动。
2. **移动优先,微信是底线场景**:以微信内 390×~700 可用高度为下限设计,手机浏览器为常态,桌面为增强。
3. **IM 习惯对齐微信**:底部 Tab、长按气泡出操作面板、输入框 + 号扩展面板 —— 用户零学习成本。
4. **场景图仍是主角**:消息层用深色半透明,不遮场景构图,热点 64×34 契约不动。

## 三、方案

### 3.1 移动端(手机浏览器 + 微信共用)

- **顶栏(40px,单行)**:左侧房间名(可点开房间列表抽屉),右侧仅"在线"状态点;退出登录/设置收进"我的"Tab。不再出现三按钮挤压标题。
- **底部 Tab Bar(56px + safe-area)**:主城 / 住宅 / 世界 / 居民 / 我的。替代汉堡抽屉,拇指可达,微信用户习惯。
- **消息气泡**:深色半透明 `rgba(22,16,12,.88)` + 1px `#3a2f28` 边框;自己=右对齐+冷青描边微光(夜霓虹),他人=左对齐;头像 24px 贴气泡上角,元信息(昵称+时间)缩为气泡内一行 10px 小字。
- **操作收敛**:长按(或右键)气泡 → 底部动作面板(编辑/撤回/复制/引用),气泡不再常驻按钮。
- **输入区**:固定底部,`env(safe-area-inset-bottom)` 垫高;左 + 号(快捷动作/颜文字/场景),输入框自适应 1-4 行,发送键仅在非空时点亮。

### 3.2 微信受限场景专项

| 项 | 做法 |
|---|---|
| 视口高度 | 弃用 `100vh`,改 `100dvh`(`100svh` 兜底),避免 WeChat 顶栏/底栏计入 |
| 浏览器回弹 | `overscroll-behavior: none` + 消息区独立滚动,防止下拉误触 WeChat 刷新/前进后退 |
| 键盘弹起 | `visualViewport` 监听,键盘弹出时输入区贴键盘上缘,消息区自动滚到底 |
| 安全区 | 底 Tab/输入区 `padding-bottom: env(safe-area-inset-bottom)`;顶栏 `env(safe-area-inset-top)` |
| 触控目标 | 所有可点元素 ≥44×44px(热点 64×34 契约不变) |
| 禁缩放误触 | 输入框字号 ≥16px(iOS 低于 16px 聚焦自动放大) |

### 3.3 桌面端

- 左栏保留但 dark-on-dark 化:active 项改为 1px 冷青左边条 + 深底,去掉金色填充;居民卡片深色化。
- 消息区限宽 720px 居中;hover 气泡右侧浮现操作图标。
- 顶栏"退出登录"改为中性描边按钮,收进右侧头像菜单。

### 3.4 视觉规范(替换 cream 的色板)

```
面板底   #16100c / rgba(22,16,12,.88)
面板边框 #2c2622,气泡边框 #3a2f28
正文     #e8ded2   次要 #9a8b7a
自己气泡描边/高亮  #57c8c2(冷青,夜霓虹,小面积)
危险动作  #c25b4e(仅动作面板文字,不大块填充)
```

## 四、落地分期

- **P0(半天)**:顶栏单行化 + 气泡深色化 + 操作收敛进长按面板。破相与违规优先。
- **P1(1 天)**:底部 Tab Bar + safe-area/dvh/overscroll/键盘适配(微信专项)。
- **P2(1 天)**:桌面端深色左栏 + 限宽消息区 + hover 操作。
- 全程不改:场景图、热点契约、昼夜切换、Gateway 合同。

## 五、明确不做

- 不改信息架构(住宅/主城/世界三入口)、不做主题换肤(霓虹主题实验仍后置)、不动 admin-ds。
- 不引入框架,保持纯静态 JS 模块现状,逐文件替换样式与少量 DOM。
