# H5 Primary Entry Reset Design

日期：2026-04-15

## 1. 背景

`lobster-chat` 最初长期按 “TUI 主战场，H5 跟随投影” 的口径推进，但当前实现已经出现两个现实变化：

1. `SFC` 风格的像素场景交互只能主要落在 `H5`；
2. `H5` 已经承担了当前内测最完整的 IM 外壳与场景承载职责。

继续维持 “TUI 是上游、H5 是投影” 的口径，会造成：

- 文档与代码现实冲突；
- `H5` 扩展长期受制于 `TUI` 语义抽象；
- `TUI/H5` 容易各自偷长私有状态；
- 每轮开发都在争论入口主次，而不是补厚共享合同。

因此本设计将当前阶段的架构口径重置为一条更贴近现实、也更便于持续演进的版本。

## 2. 新口径

### 2.1 唯一真源

唯一真源不是 `TUI`，也不是 `H5`，而是 gateway 输出的正式合同：

- `conversation_shell`
- `scene_render`

后续所有入口都必须消费这套合同，不允许任一前端再私自发明 canonical state。

### 2.2 当前主入口

当前阶段：

- `H5` 是主交互入口
- `TUI` 是并行映射客户端
- `lobster-cli` 是本地智能体入口

也就是说，这一阶段不再把 `TUI` 视作唯一先行产品面，而是把它当作与 `H5` 共享合同的终端客户端。

### 2.3 不允许的方向

本次重置后，明确不走下面两条路：

- `TUI -> H5` 单向投影依赖
- `H5 -> TUI` 单向投影依赖

正确结构应为：

- `chat-core / chat-storage / gateway contract` -> `H5`
- `chat-core / chat-storage / gateway contract` -> `TUI`
- `chat-core / chat-storage / gateway contract` -> `lobster-cli`

## 3. 当前 MVP 边界

本次重置后，当前 `MVP` 只收 5 件事：

1. `H5` 承接单城邦聊天主路径
2. `TUI` 能稳定消费同一套合同并完成主路径映射
3. `lobster-cli` 为本地智能体提供统一聊天入口
4. `conversation_shell / scene_render` 成为正式对外合同
5. 为真实 transport 与真实加密保留清晰边界

当前明确后置：

- 世界治理、举报封禁、AI 巡检产品化
- 多城邦互联产品化
- 装扮编辑器、素材系统、自由摆放
- 眼镜端适配
- `H5` 的完整离线/PWA 产品化

## 4. 直接后果

这次调整会带来 4 个直接后果：

1. `README / PRODUCT_CHARTER / IMPLEMENTATION_PHASES` 的旧口径需要同步修正。
2. `H5` 不再被描述为“轻投影”，而是“当前主入口”。
3. `TUI` 不再被描述为“唯一主战场”，而是“并行映射客户端”。
4. 后续实现优先级从“扩页面”切换成“补厚共享合同，清掉前端私货状态”。

## 5. 开发纪律

从本决议开始，后续实现统一遵守：

- 不再讨论 “到底先做 TUI 还是 H5” 这种二选一伪命题；
- 先补正式合同，再补界面细节；
- `H5` 可以继续承担主入口，但不能继续偷长私有 canonical state；
- `TUI` 可以继续推进，但目标是合同一致性和终端能力，不是重新压回上游主语；
- 非主线能力降级到维护线，不和 IM 主路径并行抢开发重心。

## 6. 与官网会审 / AI / 外挂能力的关系

这次入口重置不改变一条原则：

- `lobster-chat` 的核心通信与场景合同不能依赖外部 AI 才成立。

所以：

- 官网会审 skill、OpenClaw 助手、外部模型共审，都只能作为旁路增强；
- 不能成为 `lobster-chat` 主路径的前置依赖；
- `lobster-cli` 继续承担“给本地智能体接入统一聊天通道”的职责。

## 7. 本决议要解决的实际问题

本决议不是为了改口径而改口径，而是为了解决下面这些现实问题：

- 文档还在写 `TUI` 主战场，但实际主入口已经是 `H5`
- `H5` 需要继续承接 `SFC` 像素场景，但旧口径会持续制造架构阻力
- 共享合同已经开始形成，但上层产品口径没有同步
- 单人开发和多线并行下，必须先收敛入口、边界和主线纪律

## 8. 当前执行结论

从 `2026-04-15` 起，`lobster-chat` 当前阶段按下面这条口径执行：

- `gateway contract` 是唯一真源
- `H5` 是当前主交互入口
- `TUI` 是并行映射客户端
- `lobster-cli` 是智能体入口
- `MVP` 先收单城邦聊天主路径与正式合同
